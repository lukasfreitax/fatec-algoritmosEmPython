# 🐍 Algoritmos em Python – Treino de Laços de Repetição

Este repositório contém pequenos programas escritos em Python para treinar estruturas de repetição (`for` e `while`).  
O objetivo é praticar lógica de programação, sintaxe básica e a aplicação de loops em problemas simples.

## 📚 Conteúdo
- Contagem regressiva
- Tabuada
- Soma de números
- Impressão de padrões com `*`
- Verificação de números pares e ímpares
- Fatorial

## 💻 Tecnologias
- Python
